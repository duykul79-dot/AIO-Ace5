# AIO Ace5

AIO Ace5 module for OnePlus Ace 5 / PKG110 on ColorOS/OPlus environment.

## Current release

Version: `v3.1.3`

Author: `@keobamien`

## Main features

- Debloat
- Dọn rác
- Pin
- Hiệu năng
- WebUI
- Realtime log UI
- Cleanup completion reboot recommendation popup

## Notes

- Root environment required: KernelSU / Magisk / APatch.
- Use WebUI from the module manager after flashing.
- Some performance features may require reboot after enabling.
- Flash at your own risk.
